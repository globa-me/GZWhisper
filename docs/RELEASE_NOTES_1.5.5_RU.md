# GZ Whisper Legacy v1.5.5 · build 270829

Релиз от 10 октября 2026 года для macOS 14+ на Apple Silicon и Intel. Приложения и DMG подписаны Developer ID и заверены Apple; ZIP создан после прикрепления билета заверения.

- Приложение переименовано из GZWhisper в **GZ Whisper Legacy**: имя в Applications, заголовок окна, интерфейс, системные сообщения и пакеты сборки.
- Новые функции этой ветки заморожены. Дальнейшая поддержка — исправление ошибок, о которых сообщают пользователи. Развитие нового **GZ Whisper** для iOS и macOS продолжается в отдельном проекте.
- Сохранены bundle ID `com.gzakharov.gzwhisper`, подпись той же команды, настройки и прежние папки истории, моделей и записей. Обновление не требует переноса данных или сброса разрешений.
- Исправлена сборка ранее подготовленного тайм-аута: обработчик статуса, используемый асинхронным watchdog, объявлен как `@escaping`.
- Включены ранее подготовленные изменения: ограничение загрузки модели пятью минутами с сохранением оставшейся очереди, перетранскрибация в отдельный результат и настраиваемый ручной маркер диалога с Cmd-Shift-M. Автоматической диаризации нет.

Для обновления закройте прежнее приложение. Сохраните резервную копию `GZWhisper.app`, уберите старую копию из `/Applications` и перенесите туда `GZ Whisper Legacy.app`. Папки `Documents/GZWhisper` и `Application Support/GZWhisper` оставьте на месте. Не сбрасывайте разрешения macOS. Новый GZ Whisper использует другую идентичность приложения и развивается отдельно. Исторические публичные загрузки 1.5.4 остаются под прежним именем.

Фактические результаты сборки, подписи, заверения и установки: [документация дистрибуции](https://github.com/globa-me/GZWhisper/blob/v1.5.5/docs/MACOS_DISTRIBUTION.md).

Загрузки:

- `GZWhisper-Legacy-Installer-1.5.5-Apple-Silicon.dmg` — Apple Silicon.
- `GZWhisper-Legacy-Installer-1.5.5-Intel.dmg` — Intel.
- `GZWhisper-Legacy-macOS-1.5.5.zip` — Apple Silicon.
- `GZWhisper-Legacy-Installer-1.5.5.dmg` — тот же Apple Silicon установщик под общим именем.
- `GZWhisper-Legacy-1.5.5-SHA256SUMS.txt` — контрольные суммы пакетов.

Проверены подпись, билеты заверения, Gatekeeper и приложения внутри пакетов. Для Intel проверены исполнение Python и офлайн-импорт зависимостей под Rosetta; проверка на физическом Intel Mac остаётся рекомендованной. Linux и Windows остаются экспериментальными; новые бинарные пакеты для них в этот релиз не входят.
