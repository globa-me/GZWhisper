# GZWhisper v1.5.4 · build 270828

Исправление истории для macOS 14+ на Apple Silicon и Intel.

- Переименование в истории снова принимает пробел. Enter сохраняет название, Escape отменяет изменение. Клавиши открытия строки обрабатываются только вне поля ввода.
- Основная дата истории теперь относится к исходной записи, а транскрипция сохраняет собственную дату отдельно. Завершение транскрипции больше не перезаписывает дату записи.
- Для старых записей дата восстанавливается из временной метки в имени файла GZWhisper или из метаданных исходного медиа. Если источник недоступен, остаётся прежняя дата истории; восстановить более раннюю дату без исходного файла невозможно.
- В заголовке истории добавлена сортировка по дате записи (по умолчанию) и по дате транскрипции. Очередь остаётся сверху. Выбранный режим сохраняется между запусками.

Данные истории и медиа остаются на месте при установке обновления поверх 1.5.3.

Проверены сборки для Apple Silicon и Intel, подпись и заверение Apple. На установленной версии проверены переименование с пробелом, Enter, Escape, восстановление прежнего имени и переключатель сортировки. Подробности и контрольные суммы находятся в `docs/MACOS_DISTRIBUTION.md`.
