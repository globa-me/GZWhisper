# GZWhisper v1.5.3 · build 270827

Выпуск от 23 сентября 2026 года для macOS на Apple Silicon и Intel.

## Исправления

- Правки текста автоматически сохраняются в исходный TXT. Перед сменой элемента, экспортом и закрытием окна сохранение выполняется сразу; при ошибке переключение не стирает несохранённый текст.
- Редактор очищается при выборе задания без готового результата или при недоступном TXT. Вместо старого текста показывается объяснение состояния.
- Сегменты с таймкодами и путь использованной модели сохраняются вместе с историей. JSON после повторного открытия содержит данные результата; ручная правка текста сбрасывает устаревшие сегменты.
- Импортированные задания очереди сохраняются между запусками. Отсутствующий исходный файл помечается ошибкой.
- Повреждённый `history.json` сохраняется в отдельной резервной копии, после чего приложение пытается восстановить корректные записи. При ошибке чтения или резервного копирования запись истории блокируется и показывается уведомление.
- Ожидающее удаление записывается в журнал. После перезапуска окно Undo восстанавливается до истечения срока, затем связанные файлы отправляются в Корзину.
- Главный интерфейс ограничен одним окном, чтобы исключить конкурирующую запись общей истории. Повторное нажатие запуска записи больше не создаёт вторую сессию.

## Интерфейс и доступность

- Строки истории доступны с клавиатуры и VoiceOver. Быстрые действия появляются при фокусе; Return и Space открывают строку.
- В строках используются локализованные подписи вложений и две строки метаданных вместо короткого технического бейджа.
- Появились сочетания ⌘O для импорта и ⌘F для поиска истории; иконки действий модели получили подписи доступности.
- Статус активной модели показывает понятное название из каталога.

## Сборка

- Версия по умолчанию: `1.5.3`, build `270827`; минимальная macOS: `14.0`.
- ZIP больше не включает скрипты и инструкции для обхода Gatekeeper.
- Сборка выпуска больше не переходит автоматически на ad hoc подпись при недоступном сертификате. ZIP, DMG и notarization проверяют bundle ID `com.gzakharov.gzwhisper`, Team ID `BN3D9H4C7J` и совместимость designated requirement с установленной копией. Добавлено системное описание запроса доступа к записи экрана и звука.
- Локальные Apple Silicon приложение, ZIP и DMG собраны и нотариально заверены Apple. Приложение из ZIP и DMG прошло проверку подписи и Gatekeeper после распаковки и монтирования.
- Исходники прошли Swift typecheck для arm64 и x86_64. Во временных профилях прошли проверки очереди после перезапуска, сохранения TXT и сброса таймкодов, восстановления повреждённой истории и Undo после перезапуска.
- Профиль `GZWhisper` в Keychain доступен: прежняя ошибка была временной. Apple приняла приложение (заявка `e9f36619-47a3-4686-beef-71093726ef42`) и DMG (заявка `c08e4ebf-4f62-45da-a42b-44fe15ef89fc`); билеты прикреплены. ZIP перепакован после заверения приложения.
- Отдельные DMG для Apple Silicon и Intel также собраны и нотариально заверены. Приложения внутри обоих смонтированных образов прошли проверки подписи и Gatekeeper; исполняемые файлы и Python соответствуют заявленной архитектуре. Номера заявок и SHA-256 записаны в `docs/MACOS_DISTRIBUTION.md`.
- Предыдущая установленная 1.5.2 и новая 1.5.3 имеют одинаковое системное требование к подписи. После установки поверх 1.5.2 запись «система + микрофон» началась без повторного запроса разрешения macOS; тестовая запись удалена, прежняя история сохранилась.
- Главное окно проверено визуально после установки. На исходниках остаются предупреждения устаревших AVFoundation API; ошибок компиляции нет. Проверка на физическом Intel Mac остаётся открытой.
